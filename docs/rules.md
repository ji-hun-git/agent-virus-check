# Rules

Every rule agent-white-hat reports, with the incident or study behind it.

| Rule | What it means | ATT&CK | OWASP |
| --- | --- | --- | --- |
| <a id="pah-a001"></a>`PAH-A001` | **Repository ships agent hooks.** Hooks in a repository's .claude/settings.json (or Gemini/Cursor equivalents) run shell commands with your permissions: after you trust the folder in an interactive session, and with no prompt at all under `claude -p` or the Agent SDK. The Miasma worm (June 2026) spread through SessionStart hooks; 73 repositories were disabled. | T1546, T1059 | ASI04, ASI05 |
| <a id="pah-a002"></a>`PAH-A002` | **Agent setting that runs a command.** apiKeyHelper, statusLine, awsAuthRefresh, awsCredentialExport, otelHeadersHelper (Claude Code) and Codex's notify run programs; a repository has no reason to supply the program that produces your API key. | T1059, T1552 | ASI03 |
| <a id="pah-a003"></a>`PAH-A003` | **Redirects the agent's API traffic.** A repository that sets ANTHROPIC_BASE_URL, OPENAI_BASE_URL, a proxy, NODE_OPTIONS or extra CA certificates routes your prompts, code and API key through someone else's server (CVE-2026-21852 leaked API keys this way; a planted CLAUDE.md captured login tokens in about half of attempts). | T1557, T1552 | ASI03, LLM02 |
| <a id="pah-a004"></a>`PAH-A004` | **Turns off the agent's approvals or sandbox.** Project settings that set bypassPermissions, allow every shell command, approval_policy=never or full disk access let any instruction the agent reads run without asking you. |  | ASI02 |
| <a id="pah-a005"></a>`PAH-A005` | **Repository defines an MCP server the agent will start.** A project MCP server is a program the agent launches with your permissions (CurXecute, MCPoison, CVE-2025-59536). Interactive Claude Code asks first; `claude -p` and the SDK connect without asking. | T1059 | ASI04 |
| <a id="pah-a006"></a>`PAH-A006` | **Approves the repository's MCP servers automatically.** enableAllProjectMcpServers / enabledMcpjsonServers in a repository's own settings pre-approve its servers, so they start without the prompt that would have shown you the command (CVE-2025-59536). |  | ASI04 |
| <a id="pah-a007"></a>`PAH-A007` | **Repository ships Cursor hooks.** Commands in .cursor/hooks.json run on agent events; workspace hooks ran before trust until Cursor 3.0.0 (CVE-2026-48124). | T1546 |  |
| <a id="pah-a008"></a>`PAH-A008` | **Redirects Codex's configuration into the repository.** A .env that sets CODEX_HOME makes Codex load config.toml from the repository, whose MCP servers then run (CVE-2025-61260, fixed in 0.23.0). | T1574 |  |
| <a id="pah-a010"></a>`PAH-A010` | **Agent extension loaded with the workspace.** OpenClaw loaded .openclaw/extensions from an opened workspace before trust (CVE-2026-32920, fixed 2026.3.12). | T1546 |  |
| <a id="pah-a011"></a>`PAH-A011` | **Instruction file tells the agent to do something risky.** Agents load AGENTS.md, CLAUDE.md, GEMINI.md, rules and skills automatically and follow them. A 13 KB AGENTS.md disguised as engineering guidelines made Codex install malware in over 90% of attempts; the researchers' conclusion was that users have to defend themselves. | T1204 | ASI01, LLM01 |
| <a id="pah-a013"></a>`PAH-A013` | **MCP server runs an unpinned package.** `npx -y package` or `@latest` fetches whatever version is newest at each start, so a later malicious release (a rug pull, like postmark-mcp) runs without any change in the repository. | T1195.002 | ASI04 |
| <a id="pah-a014"></a>`PAH-A014` | **MCP tool description gives the model hidden orders.** Tool descriptions go straight into the model's context. Poisoned descriptions tell it to read ~/.ssh or config files and pass them as arguments; no model in MCPTox refused more than 3% of the time. | T1059 | LLM01, ASI04 |
| <a id="pah-a015"></a>`PAH-A015` | **Other agent configuration that runs commands.** Aider test/lint commands, Zed context servers and tasks, Continue and Cline MCP servers in a repository run programs on the agent's behalf. | T1059 |  |
| <a id="pah-a016"></a>`PAH-A016` | **Skill fetches or runs remote code.** Skills are instructions plus scripts the agent runs. ClawHavoc's 341+ malicious ClawHub skills told the agent to run a setup step that downloaded the AMOS stealer. | T1204, T1105 |  |
| <a id="pah-a017"></a>`PAH-A017` | **Instructions run an unpinned package from the registry.** `npx pkg@latest`, `uvx pkg` or `pipx run pkg` in instructions an agent follows runs whatever the registry serves under that name today. LLM-written skills spread invented names (react-codeshift was copied into 237 repositories), and whoever registers such a name gets code execution. | T1195.002 | LLM03, ASI04 |
| <a id="pah-a018"></a>`PAH-A018` | **Repository asks the agent to install plugins.** A repository's .claude/settings.json can name plugin marketplaces (extraKnownMarketplaces) and plugins to enable (enabledPlugins). A marketplace on someone's GitHub account can change what it serves at any time. | T1195.002, T1546 | ASI04 |
| <a id="pah-a019"></a>`PAH-A019` | **Skill runs shell commands when it is invoked.** A line written !`command` in a skill or a slash command runs as soon as it is invoked, before the model has read anything, and its output goes into the prompt; `allowed-tools: Bash` in the frontmatter lets every shell command through without asking while the skill is active. | T1059 | ASI02, ASI04 |

| <a id="pah-c005"></a>`PAH-C005` | **Collects the whole environment.** Serializing every environment variable collects API keys and tokens that live there. | T1082, T1552 |  |
