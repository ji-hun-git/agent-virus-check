# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussions about the work. Harassment,
personal attacks, and publishing anyone's private information are not acceptable, in issues, pull requests,
discussions or anywhere else the project is represented.

Security research is welcome here, within limits. Share bypasses privately through a
[security advisory](https://github.com/ji-hun-git/agent-white-hat/security/advisories/new), and never post live
malware, working credentials or payloads aimed at real systems.

To report unacceptable behavior, open a private advisory on this repository and say that it is about conduct, or use
GitHub's "Report content" option. Reports are handled confidentially. The maintainer may edit or remove
contributions, and block contributors, that break this code.
